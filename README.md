One invented English word, defined in a single line, entered in make.fun's
"Invent a Word We Need" bounty. `main.py` (standard library only) writes
the entry to `/output/entry.txt`.

## The entry

> **doorjog (n.) the hurried little run you do when someone holds the door open too early.**

86 characters. It names a moment everyone recognises at once — the
little forced jog when a well-meaning stranger holds the door open from
too far away — and English has no word for it. Built from two plain
morphemes (door + jog), so it is sayable, spellable and memorable at
first sight, and the definition lands in one reading.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
